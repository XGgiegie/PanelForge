# AI 漫剧角色参考图生成规范

生成单个角色的半写实电影感全身主设定图，用于后续分镜首帧和视频生成时稳定角色外观、服装、材质与体态。

设定优先级：

1. 角色名称、年龄感、身份、性格、外观、服装，以及用户明确提供的参考图。
2. 本次画面要求中的服装版本、场景、情绪、姿态与镜头倾向。
3. AI 漫剧统一视觉规范中的通用表现方式。

没有被角色设定或本次画面要求明确指定的内容，不擅自固定性别、年龄、发型、服装、季节或场景。

角色表现要求：

- 人物采用半写实骨相与精致五官，遵循真实人体比例和自然摄影逻辑，只保留轻微理想化审美，不生成卡通脸或强动画角色。
- 发丝、皮肤、眼睛、服装与配饰材质清晰；光影应显出面部结构、身体轮廓和服装层次，避免塑料人偶、蜡像脸、发光轮廓和廉价游戏建模感。
- 姿态自然、符合身份和性格，不能为了氛围牺牲角色辨识度。

固定要求：

- 必须是全身单人主设定图：从头顶到脚底完整入画，双脚和鞋履清晰可见，不得裁切头部、手部、腿部或脚部。
- 正面或轻微三分之四侧身的自然站姿，手部自然可见；构图比例以当前生成设置为准。
- 角色主体清晰，五官、发型、完整服装、配饰和体态可辨识，适合直接作为后续分镜与视频的角色视觉锚点。
- 默认使用与角色和作品相符的简洁实体背景或轻度虚化场景，以自然电影光线营造轻微梦幻氛围，不得抢占主体。
- 成图必须是完整不透明画布，不要透明底、alpha 通道、棋盘格、抠图效果或悬浮裁切感。
- 不出现其他人物、字幕、logo、水印、UI、边框、分屏、拼图、多视图设定图或九宫格。
- 有参考图时，只继承与该角色相关的外观、服装、材质和气质特征，不做拼贴，不引入无关人物。
