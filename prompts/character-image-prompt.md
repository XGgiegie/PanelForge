# 角色参考图生成规范

生成单个角色的 2D 漫剧全身设定图，用于后续分镜首帧和视频生成时保持角色外观、服装和体态一致。

固定要求：

- 必须是全身单人立绘：从头顶到脚底完整入画，双脚和鞋履清晰可见，不得裁切头部、手部、腿部或脚部
- 正面或轻微三分之四侧身的自然站姿，手部自然可见；构图比例以当前生成设置为准
- 角色主体清晰，五官、发型、完整服装、配饰和体态可辨识，适合直接作为后续分镜的角色参考
- 精致 2D 国漫短剧质感，干净线条，高级光影
- 角色背景简洁，不出现其他人物、字幕、logo 或水印
- 不要头像、半身像、特写、坐姿、3D、真人照片感、游戏 CG、多视图设定图、九宫格或分屏
- 有参考图时，优先继承参考图中与该角色相关的外观特征，不做拼贴
