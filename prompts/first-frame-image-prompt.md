# AI 漫剧首帧图提示词规范

用途：把分镜第一步编辑的内容整理成第二步“首帧图”生成提示词。

生成目标：

- 半写实电影感，按真实摄影逻辑构图与打光
- 竖屏 9:16 单张首帧构图，不做九宫格或分屏
- 能直接作为后续视频生成的第一帧与视觉锚点
- 角色外观、服装、发型、动作关系和场景空间清晰
- 真实材质与自然光影并存，梦幻感只保留为轻薄空气氛围，主体明确，画面精细、干净、有情绪张力
- 成图使用完整不透明背景

输入来源：

1. 首帧图描述
2. 分镜文本
3. 角色与用户明确添加的角色参考
4. 镜头类型
5. 旁白 / 对白
6. 补充要求

默认负向约束：

- 不要 logo、水印、无关文字或字幕
- 不要强烈动画感、平面赛璐璐、纯线稿、Q 版或低幼卡通
- 不要廉价游戏 CG、塑料材质、蜡像脸或证件照感
- 不要透明底、棋盘格、抠图边缘或悬浮人物
- 不要九宫格、分屏、脸部崩坏、多余肢体或杂乱特效
