# 2D 漫剧首帧图提示词规范

用途：把分镜第一步编辑的内容整理成第二步“首帧图”生成提示词。

生成目标：

- 2D 漫剧风格
- 竖屏 9:16 构图
- 单张首帧图，不做九宫格、不做分屏
- 能作为后续视频生成的第一帧
- 角色外观、服装、发型和场景信息清晰
- 画面精细、干净、有情绪张力

输入来源：

1. 首帧图描述
2. 分镜文本
3. 角色与角色参考
4. 镜头类型
5. 旁白 / 对白
6. 补充要求

默认负向约束：

- 不要 logo
- 不要水印
- 不要无关文字
- 不要字幕
- 不要 3D
- 不要真人照片感
- 不要游戏 CG
- 不要九宫格
- 不要分屏
